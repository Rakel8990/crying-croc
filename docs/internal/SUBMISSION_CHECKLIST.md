# NEAR Hackathon submission checklist

## Repository and README

- [ ] Keep the repository public through judging.
- [x] Include a `LICENSE` file.
- [ ] Write the README for a machine reader. Use task steps such as “Do X — see Y”; do not add marketing copy.
- [ ] List the libraries, templates, and AI-generated code used. Name Codex, Claude, and v0.

## Demo and promotion

- [ ] Keep the hosted demo available through **2026-11-18**; ideally keep it available through **2026-11-25**.
- [ ] In the demo post, say the project was built at **NEAR HACKATHON**, tag **@NEARProtocol**, include **#NEARHackathon**, and attach a video.

## Submission

- [ ] Use a **mainnet** account as the prize wallet.
- [ ] Submit once per repository. Do not resubmit the repository.
- [ ] If a submission mistake needs correction, use <https://nearhackathon.com/request-changes>.
- [ ] Submit by **2026-11-14T23:59:00Z**.
